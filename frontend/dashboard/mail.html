Mail Ballots: Received vs. Counted

Each county logs the mail ballots it receives. The Secretary of State reports the mail ballots that have been counted. This tracks the two side by side, over time, and the gap between them.

Loading…

This is not a rejection rate. The gap is ballots received but not yet counted — during voting that is mostly processing time and ballots pending a signature or ID cure, and it can even go negative when the state counts a ballot our county file hasn't captured yet. The real rejection numbers come from each county's ballot board and the post-election canvass; we will add those here once they are published. For now, watch the gap and whether it closes.

How to read this

  • Received is the count in each county's own mail roster; counted is the SOS Civix feed's counted-mail total (the authoritative accepted figure — the SOS roster undercounts it, so we don't use that).
  • A positive gap means the county has logged more received than the state has counted — normal during voting as ballots are processed and cures resolve. A negative gap means the state has counted more than our county file shows, usually a timing or definition mismatch between the two sources.
  • Hidalgo is shown but set apart — its mail file is applications for a ballot, not returned ballots, so it isn't comparable and isn't in the statewide totals.
  • Hays is sampled a few times a day (its county site blocks automated access), so its figure is noisier than the rest.
  • What it becomes: after the canvass, the gap resolves into counted-plus-rejected, and the published rejection counts drop straight into this page — turning the acceptance gap into a true rejection rate.
